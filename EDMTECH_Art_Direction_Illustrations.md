# EDMTECH Art Direction & Illustration Guidelines

## Visual Identity Overview

The EDMTECH visual identity combines **technical precision** with **human-centered innovation**. The art direction reflects a company that operates at the intersection of electronics, mechanics, and design—delivering fullstack engineering solutions.

---

## 1. Photography Style

### Overall Aesthetic
| Aspect | Direction |
|--------|-----------|
| **Mood** | Professional, innovative, trustworthy, forward-thinking |
| **Style** | Corporate technology with industrial edge |
| **Lighting** | Bright, even, cool-toned; natural light preferred |
| **Color Palette** | Cool desaturated tones—blues, greys, silvers, whites |
| **Composition** | Clean, uncluttered, with depth of field |

### Photography Characteristics

**Hero/Background Images:**
- Modern architectural spaces with glass and steel
- Technology-focused environments (labs, production facilities)
- Wide-angle shots showing scale and capability
- Subtle gradient overlays for text legibility

**Product/Project Photography:**
- Clean, well-lit product shots
- Contextual imagery showing technology in use
- Close-ups of electronic components and mechanical parts
- Hands-on shots showing craftsmanship

**People Photography:**
- Professional but approachable
- Focus on hands working on technology
- Collaborative team environments
- Avoid generic stock photos

### Color Grading
```
Temperature: Cool (slightly blue)
Saturation: -10 to -20% (desaturated)
Contrast: Medium-high
Highlights: Slightly lifted
Shadows: Deep but with detail
Vignette: Subtle or none
```

## 2. Illustration Style

### Current Website Illustrations

The EDMTECH website uses a **hybrid approach** combining photography with minimal graphic elements:

#### Area Icons (Labs, Industry, Smartcities, Mobility, Batteries)

**Visual Style:**
- **Container:** Circular mask with colored overlay
- **Background:** Photographic texture relevant to each area
- **Icon:** White, outline-style vector icons
- **Overlay Colors:** 
  - Labs: Teal (#2195BF)
  - Industry: Blue (#4F46E5)
  - Smartcities: Orange-Red (#E74F3D)
  - Mobility: Teal-Blue gradient
  - Batteries: Blue (#2195BF)

**Icon Style:**
- Thin, minimalist line art
- Single-color (white)
- Universal, recognizable symbols
- Consistent stroke weight

### Recommended Illustration Approach for Redesign

#### Option 1: Refined Current Style
Keep the circular photo + icon approach but modernize:
- Higher quality photography
- More vibrant overlay colors
- Animated hover states
- Consistent icon set

#### Option 2: Isometric Technical Illustrations
- 3D isometric style showing systems/components
- Clean lines, technical precision
- Brand colors (teal, blue, orange accents)
- Shows complexity in accessible way

#### Option 3: Abstract Geometric Patterns
- Based on logo geometry (3D faceted crystal shape)
- Minimalist patterns representing precision/innovation
- Red accent colors (#E74F3D)
- Subtle background textures

## 4. Graphic Elements & Patterns

### Geometric Patterns

**Logo Pattern (3 Bars):**
- Use as subtle background texture
- Can be animated (signal wave effect)
- Opacity: 5-10% for backgrounds
- Scale: Small (favicon size) to large (hero background)

**Grid Systems:**
- Technical blueprint aesthetic
- Light gray (#2A2A2A) on dark backgrounds
- 1px lines, 20-40px spacing
- Suggests precision and engineering

**Circuit Board Patterns:**
- Abstract circuit traces
- Teal/cyan lines on dark backgrounds
- Subtle, not overwhelming
- Connects to electronics expertise

### Decorative Elements

**Gradient Orbs/Blurs:**
- Soft, out-of-focus gradient circles
- Teal and indigo colors
- Positioned in corners or behind content
- Adds depth and visual interest
- Opacity: 20-40%

**Accent Lines:**
- 1-2px horizontal lines
- Teal color (#2195BF)
- Used to separate sections
- Or as underlines for headings

**Dividers:**
- Thin horizontal rules: 1px, rgba(255,255,255,0.1)
- Vertical dividers: Same style
- Section separators: Full width

## 5. Data Visualization Style

### Charts & Graphs

**Style:**
- Clean, minimal design
- Dark background compatible
- Teal/blue primary colors
- Orange/red for alerts/highlights

**Specifications:**
- Line charts: 2px stroke, teal color
- Bar charts: Rounded corners (4px), gradient fills
- Pie charts: Subtle shadows, clear labels
- Labels: White or light gray, Sora font

### Infographics

**Layout:**
- Clear visual hierarchy
- Numbered steps (01, 02, 03)
- Icon + text combinations
- Ample whitespace

**Typography:**
- Large numbers: 72px, light weight
- Headings: 24px, bold
- Body: 14px, regular
- All caps for labels

## 7. Animation & Motion Guidelines

### Micro-interactions

**Hover States:**
- Icons: Scale 1.1x, brightness increase
- Cards: Lift (translateY -4px), border glow
- Buttons: Gradient shift, subtle glow
- Links: Underline animation

**Scroll Animations:**
- Fade in from bottom (content blocks)
- Parallax on hero images (subtle)
- Staggered reveal for grid items
- Counter animation for statistics

**Loading States:**
- Pulsing gradient orbs
- Logo icon animation (signal bars)
- Skeleton screens matching content layout

### Transition Timing

```css
Default: 300ms ease
Fast: 150ms ease
Slow: 500ms ease
Bounce: cubic-bezier(0.34, 1.56, 0.64, 1)
```

## 8. Image Treatment Examples

### Hero Image Treatment

**Process:**
1. Select high-quality architectural or tech photography
2. Apply cool color grading (blue/cyan shift)
3. Add subtle gradient overlay (dark to transparent)
4. Ensure contrast for white text
5. Optional: Add subtle geometric pattern overlay (5% opacity)

### Project Card Images

**Process:**
1. Product or contextual photography
2. Consistent color grading
3. Rounded corners (12-16px)
4. Subtle shadow
5. Hover: Scale 1.02x, shadow increase

### Team/People Images

**Process:**
1. Professional headshots
2. Consistent background (studio or office)
3. Cool, even lighting
4. Grayscale or desaturated color treatment
5. Optional: Teal duotone overlay

## 9. Art Direction Do's and Don'ts

### ✅ DO

- Use cool, desaturated color palettes
- Maintain high contrast for accessibility
- Show real technology and workspaces
- Use consistent lighting across photos
- Apply subtle gradient overlays for text legibility
- Use geometric patterns inspired by the logo's faceted shape
- Keep icons minimalist and consistent
- Add depth with gradient orbs

### ❌ DON'T

- Use warm, saturated colors
- Use generic stock photography
- Clutter compositions with too many elements
- Use heavy filters or effects
- Mix illustration styles
- Use busy patterns as backgrounds
- Use inconsistent icon styles
- Apply heavy drop shadows

## 10. File Formats & Delivery

### Photography
- **Format:** WebP (primary), JPG (fallback)
- **Resolution:** 2x for retina displays
- **Compression:** 80-85% quality
- **Max Width:** 1920px for hero, 800px for cards

### Illustrations & Icons
- **Format:** SVG (scalable), PNG (fallback)
- **Color Mode:** RGB
- **Optimization:** SVGO for SVGs
- **Sizes:** 24px, 48px, 96px, 192px

### Logos
- **Format:** SVG (primary), PNG (fallback)
- **Variants:** 
  - Full color (gradient)
  - White
  - Black
  - Icon only
- **Sizes:** All scales from 16px to 1000px
